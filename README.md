# Код курса по LangGraph

Здесь лежат запускаемые примеры из уроков курса. Папка на урок, имена файлов совпадают с именами примеров в тексте урока.

В курсе восемь уроков, код выложен ко всем.

## Как запустить

Нужен Python 3.10 или новее, примеры запускались на Python 3.12. Окружение ставится в корне репозитория. На macOS и Linux:

```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

На Windows:

```
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Файл `.env` положите в корень репозитория или в папку урока: `course_model.py` ищет его от своей папки вверх. Что в нём лежит, разобрано в уроке 1, раздел "Окружение и стенд для примеров". Ключ нужен только примеру 5 урока 1.

Пример запускается из папки своего урока:

```
cd lesson_01
python 01_first_graph.py
```

## Что в репозитории

- `lesson_01`, граф вместо готового цикла: первый StateGraph из двух узлов, что проверяет компиляция, параллельные узлы в одном шаге, запуск в потоках updates и values и схема графа, агент из create_agent как граф. Рядом стенд `mini_repo`, выдуманный сервис из четырёх файлов, его разбирают примеры
- `lesson_02`, состояние графа: три способа задать схему состояния, редьюсер, почему списку сообщений нужен add_messages, обход редьюсера типом Overwrite, схемы входа и выхода, приватный ключ и контекст запуска, каналы под схемой состояния. Рядом копия стенда `mini_repo`
- `lesson_03`, ветвление: условное ребро и функция маршрутизации, Command вместо пары "обновить состояние и перейти", что попадает на схему графа, Send и раскладка работы по числу файлов, ветки разной длины и итоговый узел. Рядом копия стенда `mini_repo`
- `lesson_04`, циклы и остановка: ребро назад и условный выход на END, предел шагов recursion_limit и GraphRecursionError, остаток шагов RemainingSteps и выход без ошибки, повтор узла и идемпотентные побочные действия, кеш узла. Рядом копия стенда `mini_repo`
- `lesson_05`, checkpointer: thread и история состояний, продолжение запуска в новом процессе после сбоя с SqliteSaver, режимы durability, правки задач упавшего шага, повтор от прошлого checkpoint, исправление состояния методом update_state и развилка. Рядом копия стенда `mini_repo`
- `lesson_06`, пауза и человек в цикле: пауза interrupt() внутри узла и возобновление с Command(resume), пауза, которая ждёт ответа в файле базы SQLite под SqliteSaver, решения одобрить, исправить или отклонить со схемой ответа, несколько пауз в одном шаге и ответ по id, пауза внутри инструмента, четыре правила паузы. Рядом копия стенда `mini_repo`
- `lesson_07`, подграфы: слой как подграф узлом родительского графа с общими ключами и со схемами входа и выхода, вызов подграфа внутри узла функцией-обёрткой, пауза внутри подграфа и возобновление, параметр checkpointer у подграфа со значениями None, True и False, поток из подграфа с subgraphs=True, переход в узел родителя с Command.PARENT. Рядом копия стенда `mini_repo`
- `lesson_08`, когда узел падает: повторные попытки с RetryPolicy и выбор ошибок для повтора retry_on, таймаут попытки и таймаут простоя узла, обработчик ошибки error_handler и NodeError, остановка запуска по запросу RunControl и продолжение после неё, отладка графа без внешнего сервиса. Рядом копия стенда `mini_repo` и стенд `bad_repo`: файл с ошибкой, зависший файл, долгий файл с выводом о ходе работы и файл без ошибок
